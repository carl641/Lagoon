# Lagoon Marketing - Gulf Shores, Alabama

A professional, water-themed marketing website for Lagoon Marketing, serving businesses in Gulf Shores, Alabama and the surrounding coastal Alabama area.

## Overview

This is a fully responsive, SEO-optimized website featuring a beautiful water-themed design that reflects the coastal nature of Gulf Shores, Alabama. The site is built with clean HTML5, CSS3, and vanilla JavaScript for optimal performance and compatibility.

## Features

### Design
- **Water-Themed Color Palette**: Ocean blues, teals, and aqua colors throughout
- **Responsive Layout**: Mobile-first design that works on all devices
- **Modern CSS**: CSS Grid and Flexbox for layouts
- **Smooth Animations**: Subtle scroll animations and transitions
- **Accessibility**: ARIA labels, semantic HTML, keyboard navigation support

### Pages
1. **Home (index.html)**: Hero section, service preview, company overview
2. **Services (services.html)**: Detailed service offerings including SEO, web design, social media, content marketing, PPC, and email marketing
3. **Cities We Serve (cities.html)**: Geographic coverage including Gulf Shores, Orange Beach, Foley, Fairhope, Daphne, and more
4. **Contact (contact.html)**: Contact form with validation, business information, FAQ section

### SEO Optimization
- **Meta Tags**: Comprehensive meta descriptions, keywords, Open Graph, and Twitter Cards
- **Schema.org Markup**: LocalBusiness and Service structured data
- **Semantic HTML**: Proper heading hierarchy and HTML5 elements
- **Sitemap**: XML sitemap for search engines
- **Robots.txt**: Configured for optimal crawling
- **Geo Tags**: Location-specific metadata for Gulf Shores, AL
- **Local SEO**: City-specific content and service area markup

### Interactive Features
- Mobile navigation menu
- Smooth scrolling for anchor links
- Contact form validation
- Phone number formatting
- Scroll animations (Intersection Observer)
- Form error handling
- Responsive header effects

## Customization

### Colors
All colors are defined as CSS custom properties in `css/styles.css` under the `:root` selector. Modify these to change the color scheme:

```css
:root {
    --ocean-blue: #006994;
    --lagoon-teal: #00A9CE;
    /* ... more colors */
}
```
